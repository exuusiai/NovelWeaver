# NovelWeaver 演示视频脚本

> 目标时长 3 分钟（也可只录每镜 1-2 条取最好剪成 90 秒精简版）。目标观众：招聘方/面试官，只有 3 分钟耐心。
> 叙事主线：**真实的写作流 → AI 治理设计 → 实验驱动的检索优化**，三段各有一个记忆点。

## 录制前准备清单

- [ ] 分辨率 1920×1080，浏览器全屏、隐藏书签栏；系统显示缩放调大一档（观众要在手机上看清字）
- [ ] 服务已启动（`pnpm dev`），**已配置模型与 Embedding**（设置页 → 模型网关 → 保存并测试；Embedding 模型填 GLM-Embedding-3，等记忆回填到 100%——设置页字段下方有覆盖率提示）
- [ ] 数据状态：霍比特人项目已完成分析（20 章/155 设定/119 事件）；雾港纪事序章有正文、有一条"未回收伏笔"审查项
- [ ] 终端字体调大（18pt+），预先 `clear`
- [ ] 录制工具：QuickTime（屏幕录制）或 OBS；剪辑+字幕用剪映/CapCut
- [ ] 每个镜头单独录 2 条，剪辑时取最好——不要一口气连录

## 录制与发布建议

- **B 站/YouTube 放完整版**，README 顶部嵌 15-20 秒 GIF 摘要（镜头 6 + 8）+ 视频链接（GitHub README 不支持直接内嵌视频播放）
- GIF 转换：`ffmpeg -i demo.mp4 -vf "fps=12,scale=960:-1:flags=lanczos" -t 20 demo.gif`
- 口误不用重录整段：每个镜头独立录制，剪辑时拼接
- 旁白可后期配，也可先写字幕直接录屏（字幕版成本更低，效果差距不大）
